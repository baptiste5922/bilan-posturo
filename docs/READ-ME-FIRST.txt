POSTURAL ASSESSMENT — Installing on the practice PC
====================================================

English translation of LISEZMOI.txt, which is the version shipped
to the practice and the reference for installation.

This folder contains everything needed. Nothing to install but
Python 3 (python.org), plus one library for the certificates only.


FIRST INSTALLATION — in this order
----------------------------------

1. Rename this folder to:  BilanPosturo
   and put it in, for example, C:\BilanPosturo

2. Open a terminal (PowerShell on Windows) and go there:

       cd C:\BilanPosturo

3. Install the library used to create the certificates:

       python3 -m pip install cryptography

4. Set the username and password:

       python3 serveur/serveur.py --config

5. Note this PC's IP address (command: ipconfig) and RESERVE it
   on the router, so that it stops changing.

6. ONLY THEN, generate the encryption certificate with that
   address:

       python3 serveur/generer_autorite.py 192.168.1.42

   The order matters: the certificate is tied to the IP address.
   Created before the address is fixed, it has to be redone.

7. Install autorite.crt on the tablet and on this PC, otherwise
   the browser will refuse the connection:

       Android — Settings, Security, Encryption & credentials,
                 Install from storage, CA certificate
       Windows — Import-Certificate -FilePath autorite.crt
                 -CertStoreLocation Cert:\CurrentUser\Root

8. Start:

       python3 serveur/serveur.py

   The displayed address must begin with https.

9. Install the automatic start, so the server never has to be
   launched by hand. Right-click the file, "Run with
   PowerShell", as administrator:

       installer-demarrage.ps1

   The server then starts with the PC, even with nobody logged
   in, and restarts itself if it stops. The script also opens
   the firewall port and prints the address to use on the
   tablet.


EVERY MORNING
-------------

   Nothing to do: the server starts with the PC.

   If the automatic start was not installed (step 9),
   double-click demarrer-serveur.bat every morning and leave
   the window open all day; closing it stops the service.


BETWEEN TWO PATIENTS
--------------------

   On the tablet, tap "Nouveau bilan" (New assessment).
   Reloading the page is not enough: the previous assessment
   would be offered for recovery.


WHERE THE FILES GO
------------------

   bilans/        the PDFs received from the tablet (patient data)
   journal.log    timestamp of every access and every delivery
   config.json    username and password digest
   cle.pem        private encryption key

   The last three must NEVER be copied, sent or shared. The
   bilans/ folder, on the other hand, must be included in the
   practice backup.

   To send the PDFs somewhere other than bilans/, edit the
   "dossier_pdf" line in config.json.


IF SOMETHING GOES WRONG
-----------------------

   Forgotten password
       python3 serveur/serveur.py --config

   The tablet shows "ERR_CONNECTION_REFUSED"
       The PC answered, but the server is not running on it.
       So it is not the Wi-Fi. On the PC, check:

           Get-ScheduledTask -TaskName BilanPosturo

       If the state is not "Running", restart it:

           Start-ScheduledTask -TaskName BilanPosturo

       If the task does not exist, the automatic start was
       never installed: do step 9.

   The tablet shows "ERR_CONNECTION_TIMED_OUT"
       The PC did not answer at all: switched off, on another
       network, or its IP address changed. Note it (ipconfig),
       reserve it on the router, then REDO step 6.

   A banner announces assessments waiting
       The server was not answering when they were sent. They
       are held on the tablet and will go out on their own once
       the server answers. Nothing is lost and nothing has to be
       transferred by hand: restart the server and leave the
       page open.

   To check the server from any device in the practice, open
   https://<pc-ip>:8000/sante — {"etat":"ok"} means it answers.

   Check journal.log: it shows whether an assessment was
   received, and at what time. Past 5 MB it is archived as
   journal.log.1, and so on up to journal.log.3.
