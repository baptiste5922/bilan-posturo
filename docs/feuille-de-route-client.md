# Feuille de route — votre fiche de bilan sur mesure

**À remplir avant le devis.** Comptez 20 à 30 minutes. Vous décrivez la fiche
que vous voulez ; nous la fabriquons. Vous n'aurez jamais à la construire
vous-même.

> **Le plus utile de tout : joignez votre fiche actuelle**, papier scanné, PDF
> ou photo, même raturée. C'est la meilleure description possible de votre
> façon de travailler. Le reste de ce document sert à lever les ambiguïtés
> qu'une fiche papier laisse toujours.

Une règle à garder en tête en remplissant : **la fiche affiche exactement le
texte que vous écrivez ici**, ponctuation et majuscules comprises. Nous
n'inventons ni libellé ni abréviation, et nous ne corrigeons un mot que si vous
nous y autorisez (section 9).

## 4. Le contenu de chaque partie

Pour chaque partie, listez ses champs. Pour chaque champ, choisissez **une** des
formes ci-dessous : ce sont les seules que la fiche sait afficher, et elles
couvrent la quasi-totalité des bilans que nous avons rencontrés.

| Forme | À quoi ça ressemble | Exemple |
|---|---|---|
| **Ligne** | Une ligne de texte libre | Sport, Métier, Pointure |
| **Zone** | Plusieurs lignes, qui s'agrandissent en écrivant | Motif de consultation, Conseils |
| **Date** | Un sélecteur de date | Date du bilan |
| **Case** | Une case à cocher, oui ou non | Pouls pédieux, Chaussures usées |
| **Choix** | Une seule réponse parmi plusieurs, à lister | Appui : Antérieur / Postérieur |
| **Tableau G/D** | Plusieurs lignes, une seule réponse par ligne parmi des colonnes | Rotation tête : Positif — Gauche / Droite |
| **Schéma** | Une image à annoter au stylet | Squelette de dos, empreintes |

Modèle, à recopier pour chaque partie :

**Partie n° …… — « …………………… »**

| Libellé exact | Forme | Options (pour Choix et Tableau) | Remarque |
|---|---|---|---|
| | | | |
| | | | |
| | | | |

**Mise en ligne.** Par défaut, les champs d'une partie s'empilent. Si
plusieurs champs doivent tenir sur une même ligne (ex. « Pointure ville »,
« Pointure sport », « Base » côte à côte), précisez-le dans la colonne
Remarque.

### Ce qui demande un signalement à part

Signalez-les explicitement : ils ne relèvent pas des formes ci-dessus et sont
chiffrés séparément.

- **Grille de cases.** Plusieurs réponses possibles sur une même ligne, par
  exemple un test positif à gauche *et* à droite, sur sol dur *et* sur mousse.
- **Grille de mesures.** Des valeurs à saisir dans chaque case : Maddox,
  MCP, cotations par position.
- **Cellules barrées** ou **colonnes regroupées** sous un en-tête commun.
- **Valeur calculée** à partir d'autres champs (indice, total).

☐ Ma fiche comporte des grilles : je les signale, partie par partie, dans la
colonne Remarque.

### Ce que la fiche ne fait pas, volontairement

- **Aucun champ n'est prérempli** avec une valeur clinique. Une valeur par
  défaut finit tôt ou tard sur le bilan d'un patient qui n'en avait pas.
  Un texte d'aide grisé, qui disparaît à la saisie, reste possible.
- **Pas de liste déroulante** : un Choix à pastilles se touche en un geste
  sur tablette, une liste en demande trois.
- **Pas de champ obligatoire** bloquant : la consultation n'attend pas la
  fiche.

## Après la livraison

Les demandes de modification (« ajoutez-moi un champ ») sont recueillies au fil
de l'année et livrées **en une révision annuelle, incluse dans l'abonnement**.
Une modification urgente peut être faite hors révision ; elle est alors
facturée à part.
