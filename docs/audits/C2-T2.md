  ni `tar` du dépôt : aucun fichier réel du cabinet (ignorés par Git) n'est copié.

  trouvé zéro ou deux fois), le fichier restauré dans un `finally`, le code de
  sortie lu sur **la commande de test elle-même**.

  que les fichiers de la tâche.

## Deux précisions sur le contrat

1. **M5 et le lien interne.** Le contrat attend que M5 rougisse par le test du
   *lien interne*. Ce n'est pas le cas, et ça ne peut pas l'être : l'étape 4
   (`reel != attendu → lien-symbolique`) refuse déjà un lien interne même sans la
   boucle `islink`. Le motif est le même, donc le test ne distingue pas. M5 rougit
   par les liens **vers l'extérieur** (sans la boucle, le motif devient
   `hors-racine`) ; l'étape 4 a sa propre mise en échec, M5b, par un test qui
   simule une jonction invisible à `islink` (`unittest.mock`, `islink → False`).
   Aucune des deux couches n'est donc redondante *pour les tests* ; elles le sont
   pour le résultat sur un lien interne, ce qui est voulu (défense en profondeur).
2. **Les doubles Node existants n'ont pas eu besoin d'être complétés**
   (`tests/test_nommage.js`, `tests/test_concurrence_export.js`,
   `tests/test_export_grille.js`) : leurs réponses de `/cabinet` ne portent pas de
   clé `logo`, donc `appliquerLogo()` masque l'image et `logoPret()` résout aussitôt
   sans toucher à `getAttribute` ni à `complete`. Le contrat n'exigeait la
   modification que « si nécessaire » : les trois suites sont vertes, inchangées.
